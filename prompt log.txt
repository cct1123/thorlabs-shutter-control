## Objective

Develop a reliable control program for a Thorlabs KSC101 K-Cube Solenoid Controller and connected optical shutter.

* a simple reusable Python controller class;
* reliable shutter open/close control;

## Technical constraints

* Use Python.

* Prefer official Thorlabs-supported APIs/libraries where practical.

The controller interface should support, where appropriate:

* connect
* disconnect
* identify device

* close shutter

* clear handling of communication errors

## GUI requirements

The Dash GUI should minimally show:

* connection status
* device identity / serial number
* shutter state where available
* Open button
* Close button
* status/error messages

Keep the GUI simple and functional.

## Validation

* device discovery/connection;
* open;
* close;
* repeated open/close operation;
* disconnect/reconnect;
* error handling;
* defined shutdown behavior;
* GUI operation through the controller class.

Do not treat successful software calls alone as proof of physical shutter operation.
